# 🎬 Netflix Clone

A responsive **Netflix landing page clone** built using **HTML5** and **CSS3**. This project recreates the look and feel of Netflix's homepage with a clean UI and responsive design.

## 🚀 Features

- 🎥 Netflix-inspired UI
- 📱 Fully responsive design
- 🧭 Navigation bar
- 🖼️ Hero banner section
- 🎞️ Movie and TV show sections
- ✨ Hover effects
- 🌐 Cross-browser compatible

## 🛠️ Technologies Used

- HTML5
- CSS3
